# Brand logos

These files identify the phone brands in the profile grid. They are used only for identification;
all brand names and logos are trademarks of their respective owners. CleanYourPhone is not affiliated
with, endorsed by, or sponsored by any of these companies.

The source files were downloaded from Wikimedia Commons on 2026-11-02, converted to transparent PNG
without recoloring or stretching, trimmed and resized to 128 px height. The originals are kept in
`source/`.
