How it works

Three steps. You stay in control.

  1. 01

    Connect locally

    Open the app or the repo, enable USB debugging and connect the phone. The tool checks ADB and the device before anything changes.

  2. 02

    Review

    Back up packages, roles and settings. Review DISABLE, ASK, BLOCKED and SKIP for every package. Nothing changes yet.

  3. 03

    Apply or restore

    Apply in batches of five. Verify. Restore exactly what the journal recorded; the backup is the fallback.

Safety

Safe by design. Boring on purpose.

Disable, never uninstall

Only pm disable-user --user 0. No uninstall, hide, clear or root. pm enable is the undo.

Back up first

Packages, roles, IME, settings and getprop are saved before the first change. No backup, no changes.

Protected list and roles

Telephony, Play Services, WebView, permissions, emergency alerts, dialer, SMS, Home and keyboard are refused or checked.

Small batches, clear undo

Five packages, verify, then the next batch. The journal is exact; if it is lost, the backup reconstructs the change.

Runs locally: no CleanYourPhone-hosted service, no account, no telemetry. Read the safety rules ↗

FAQ

Short answers.

Is it safe?

Safer than a copied package list, but not magic. It never uninstalls, backs up first, refuses protected packages and role holders, disables in small batches and can restore every change the CLI recorded. You still review the plan and test calls, SMS, camera, keyboard, Home and notifications.

Does it uninstall anything?

No. The only state change is pm disable-user --user 0. No uninstall, hide, clear or root. pm enable is the undo.

What if something goes wrong?

Stop. Run restore if ADB still sees the phone. If the undo journal is lost, run restore --from-backup <folder> and review the list. If the phone does not boot, the recovery guide covers safe mode, ADB and recovery; factory reset is the last resort.

Why disable instead of uninstall?

pm uninstall --user 0 removes the package for the main user and can complicate OTA updates, factory-reset expectations or OEM restore flows. pm disable-user --user 0 freezes it in place and reverses with pm enable.

Does it work on tablets?

Yes, on Android 8+ with ADB. Tablet profiles set form_factor: tablet; a missing dialer or SMS role is a warning, not a failure. Home and keyboard checks still apply.

Is it free?

Yes. MIT license. No account, no subscription, no telemetry and no CleanYourPhone-hosted service.
